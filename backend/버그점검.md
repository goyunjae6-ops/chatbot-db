## 1. 없는 함수를 부른다 (70줄)

`main.py`는 `db.read_messages()`를 부른다.

그런데 `db.py`에 있는 이름은 `read_message`다. **s가 없다.**

그래서 메시지 목록을 불러오면 터진다.

```python
# main.py 70줄
@app.get("/sessions/{session_id}/messages")
def list_messages(session_id: int):
    return {"messages": db.read_message(session_id)}   # read_messages -> read_message
```

`db.py` 쪽 이름을 `read_messages`로 바꿔도 된다.

그럼 41줄의 `build_history`도 같이 바꿔야 한다.

## 2. 대화기록을 이중으로 감쌌다 (33줄)

`ask_ai`는 이제 **리스트**를 받는다.

리스트는 이미 `[{role, content}, ...]` 모양이다.

그런데 그걸 또 `content` 칸에 집어넣었다.

```python
# 지금 (틀림)
"messages": [{"role": "user", "content": history}],
```

`content`는 글자여야 하는데 리스트가 들어갔다.

서버가 거부한다.

```python
# main.py 28~38줄 수정본
def ask_ai(messages):
    token = os.getenv("HF_TOKEN")
    headers = {"Authorization": f"Bearer {token}"}
    payload = {
        "model": HF_MODEL,
        "messages": messages,   # 그대로 넘긴다. 감싸지 않는다.
        "max_tokens": 1000,
    }
    res = requests.post(HF_URL, headers=headers, json=payload)
    res.raise_for_status()      # 실패하면 여기서 바로 알려준다
    data = res.json()
    return data["choices"][0]["message"]["content"]
```

## 3. `/chat`은 옛날 방식이다 (51줄)

`ask_ai`가 리스트를 받게 바뀌었다.

그런데 `/chat`은 아직 글자를 그대로 넘긴다.

```python
# main.py 49~52줄 수정본
@app.post("/chat")
def chat(msg: Msg):
    reply = ask_ai([{"role": "user", "content": msg.text}])   # 리스트로 감싼다
    return {"reply": reply}
```

## 참고: bot 이라는 역할 이름
